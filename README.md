# 璀璨圣诞树 · Merry Christmas

一个可在浏览器中体验的 3D 圣诞树互动页面，支持手势控制、照片轮播、音乐和飘雪。

## 在线体验

- 电脑版（完整效果）：https://panaoran813-byte.github.io/christmas-tree/
- 手机轻量版：https://panaoran813-byte.github.io/christmas-tree/?lite=1

手机上建议使用 Safari 或 Chrome。微信内置浏览器若无法调用摄像头，请选择“在 Safari 中打开”。

## 使用方法

1. 打开网页，点一下画面进入。
2. 在相册面板中添加照片。
3. 点击右上方的相机/手势按钮，并允许网页使用摄像头。
4. 在摄像头前做手势：
   - 张开手掌：圣诞树粒子绽放。
   - 握拳：粒子回到树形并保持聚合。
   - 拇指和食指捏合后松开：切换到下一张照片；轮完后从第一张开始。
5. 可使用鼠标拖动或触屏操作来调整视角。

## 隐私说明

- 上传的照片保存在当前设备、当前浏览器的网站本地数据库中，不会写入本 GitHub 仓库。
- 当前版本没有将照片上传到服务器或发送给网页所有者的功能；照片展示使用浏览器本地对象地址。
- 摄像头画面由浏览器中的 MediaPipe 手势识别处理，当前代码没有把摄像头画面发送到服务器。
- 同一设备、同一浏览器配置下再次打开页面时，本地照片会保留；共用同一浏览器的人可能看到这些照片。
- 清除浏览器中此网站的数据会删除本地保存的照片。不同设备、不同浏览器配置之间不会自动同步。

## 仓库内容

当前仓库包含可直接由 GitHub Pages 发布的静态构建文件：

- `index.html`：网页入口。
- `assets/`：构建后的 JavaScript 和 CSS。
- `mediapipe/`：手势识别运行时文件。
- `audio/`：页面音乐资源。

当前仓库没有原始 React/TypeScript 开发源码；交互逻辑保存在构建后的 JavaScript 文件中。

## 发布

GitHub Pages 从 `main` 分支的根目录发布。修改仓库内容后，GitHub Actions 会自动构建并部署。
